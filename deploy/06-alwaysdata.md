# ۶ — اجرا روی Alwaysdata

دو راه داری؛ راه اول اصلاً به کد نیاز ندارد.

## راه اول — پنل خود alwaysdata (بدون کد، پیشنهادی)

این دقیقاً همان Reverse Proxy است که در فایل `untitled.txt` آمده:

1. وارد حساب alwaysdata شو.
2. **Websites** → **Add a website**.
3. به‌جای PHP یا Python، نوع **Reverse Proxy** را انتخاب کن.
4. این‌ها را بده:
   - **دامنه** خودت (مثلاً `api.example.com`)
   - **آدرس مقصد** (مثلاً `https://external-server.com:8080`)
5. ذخیره کن.

تمام. نه کدی لازم است، نه کلیدی، نه چیز دیگر. فقط آدرس مقصد را داده‌ای.

## راه دوم — اجرای همین کد به‌عنوان سایت Python

اگر به هر دلیلی می‌خواهی همین کد روی alwaysdata اجرا شود:

1. فایل‌های پوشه `proxy-minimal` را در حساب alwaysdata آپلود کن.
2. یک سایت Python بساز و فایل اجرایی را `proxy.py` مشخص کن.
3. پورت داخلی را طبق چیزی که پنل می‌خواهد تنظیم کن (در فایل اصلی برای
   Node.js همین‌طور گفته شده بود: زبان برنامه، مسیر فایل و پورت داخلی).
4. در متغیرهای محیطی همان سایت، فقط این را ست کن:
   ```
   TARGET_BASE_URL=https://آدرس-مقصد-خودت
   ```
5. اگر پنل دستور شروع (start command) خواست، این را بده:
   ```bash
   uvicorn proxy:app --host 0.0.0.0 --port $PORT
   ```
   (`$PORT` همان پورتی است که alwaysdata به برنامه می‌دهد.)
6. دامنه‌ات را به این سایت وصل کن و تست کن:
   ```
   https://دامنه-خودت/health
   ```

## کدام راه؟
- اگر فقط یک آدرس را می‌خواهی به دامنه‌ات وصل کنی، **راه اول** ساده‌تر است
  و اصلاً کد نمی‌خواهد.
- اگر رفتار پروکسی را خودت می‌خواهی کنترل کنی (مثلاً بعداً چیزی به آن
  اضافه کنی)، **راه دوم** با همین کد است.
