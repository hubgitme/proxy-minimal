# راهنمای استقرار — فهرست جدا برای هر سرویس

هر فایل یک سرویس را کامل و مستقل توضیح می‌دهد؛ برای اجرا فقط همان یک فایل را بخوان:

| فایل | سرویس | مناسب برای |
|---|---|---|
| `01-local-windows.md` | کامپیوتر خودت (ویندوز) | تست سریع، قبل از استقرار |
| `02-koyeb.md` | Koyeb | جایگزین رایگان پیشنهادی |
| `03-railway.md` | Railway | جایگزین ساده از روی GitHub |
| `04-render.md` | Render | جایگزین با پلن رایگان |
| `05-vps-docker.md` | VPS خودت با Docker | کنترل کامل، بدون خوابیدن سرویس |
| `06-alwaysdata.md` | Alwaysdata | بدون کد (پنل) یا با همین کد (سایت Python) |

در همه روش‌ها فقط یک چیز را ست می‌کنی: `TARGET_BASE_URL` (آدرس مقصد).
جایی که نباید اجرا شود: Vercel، Netlify و Cloudflare Workers — این کد یک سرور
Python دائمی است و روی آن‌ها کار نمی‌کند.
